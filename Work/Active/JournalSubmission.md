## Spec

Origin: "you should definitely add this stylesheet https://www.complex-systems.com/contribute/ — perhaps even a button in the palette publish to complex systems or publish to arxiv".

The paclet ships four LaTeX journal templates and no Wolfram-adjacent one, which is the odd gap given who writes in notebooks.
*Complex Systems* publishes its author instructions and class file at <https://www.complex-systems.com/contribute/>; a fifth template stylesheet generated from the same base cell list would let a paper be written to that journal's geometry from the first cell.

The second half of the request is a different kind of thing: not a stylesheet but a submission path — one button that produces whatever the journal or arXiv actually wants (a LaTeX source tree, a PDF, a figure directory) from the open notebook, rather than the author assembling it by hand.
That leans on `ConvertMathCells` and the LaTeX export side and is the larger, vaguer half; scope it only after the stylesheet exists.

Done when a notebook can be written in a `ComplexSystems` template that matches the journal's own geometry, and a submission button produces a bundle the journal accepts without hand-editing.

### Requirements

- **Read the actual instructions and class file** from complex-systems.com before choosing any measurement; do not infer the geometry from the PDF.
- **A fifth template** generated by `Scripts/BuildStyleSheets.wls` from the same base cell list as the other four, chaining to `Default.nb` and declaring identical style names — `Tests/StyleSheets.wlt` enforces that.
- **Submission bundle**, per target: what arXiv wants (LaTeX source + figures, no PDF-only) is not what a journal wants (often PDF plus source). Decide per target rather than shipping one generic "export".
- **Palette buttons** in whatever group ends up owning export.

### Edge cases & out of scope

- The journal's class file may not be redistributable; check before vendoring it.
- Round-tripping a *whole* paper through LaTeX is the `LaTeXPaperImport` item's problem, and a submission bundle depends on it being good enough — sequence accordingly.
- Out of scope: actually uploading to arXiv or a journal's submission system.
